# Cross-lecture connections

Use when prior files/guides/a directory are supplied or a specific earlier
relationship needs inspection. The current concept map determines retrieval targets.

## Retrieve for a learning need

1. Identify current concepts with assumed prerequisites, reused methods, unexplained
   transitions, or likely contrasts. Form a small set of concept/symbol/synonym queries.
2. Inspect the supplied prior-material inventory and reliable lecture identifiers.
   Search headings/text when available; read matched sections with surrounding
   definitions, equations, or diagrams. Inspect visual evidence if extraction misses it.
3. Check that a match describes the same concept and context, not merely the same
   word. Verify notation and assumptions before declaring equivalence.
4. Classify the relationship below, then ask what misunderstanding or missing step
   it resolves. Add a connection only if the learner benefits from the answer.

Targeted retrieval is enough; do not load every earlier file in detail or dump its
contents into the guide. Search alternatives when terms differ. Stop expanding the
search when the needed relationship is established or accessible supplied sources
do not support it. Do not turn a simple guide into a history of the course.

## Choose the relationship

| Type | Evidence test | Useful teaching contribution |
| --- | --- | --- |
| **Prerequisite** | The current explanation requires a model/method established earlier. | Recall the necessary premise and show where it enters the current reasoning. |
| **Continuation** | The current unit extends the same earlier idea with a new mechanism, precision, or case. | Explain what stays the same and what the new lecture adds. |
| **Contrast** | Similar prior/current concepts differ along a meaningful dimension. | Name that dimension and prevent transferring the wrong assumptions. |
| **Reuse / Application** | An earlier tool/model is used in a new context. | Trace the reused operation and explain its new role. |

Choose the primary learning relationship if more than one fits. No extra category
is needed merely to accommodate a loose association. If a keyword match cannot
answer the evidence test, omit it.

## Write a concise connection

Use **Previous Lecture Connection** with the selected relationship type, an
evidenced lecture/section name, a brief recap, and the specific current use.
Usually a few sentences suffice.
For example, if both supplied sources support it:

> Previous Lecture Connection — Prerequisite
>
> Lecture 2 introduced convolution as a sliding weighted sum. The filtering step
> here uses that operation, so the earlier model explains how to read this formula.

Place the note where the relationship helps, normally before the dependent concept
or next to the useful contrast. Avoid repeatedly recapping the same prerequisite;
link to an earlier guide section or use a brief reminder after its first explanation.
Do not add references merely to prove prior files were read.

## Handle incomplete or conflicting context

If a supplied path is unavailable, try an accessible provided alternative and
state the narrow limitation. Use the current lecture to explain necessary context
without claiming it came from an unread prior lecture. If previous knowledge is
assumed explicitly, respect it; a topic assertion alone cannot verify an exact
earlier lecture quote or diagram.

A previous study guide is secondary evidence. Resolve important disagreement with
its original lecture when accessible; otherwise disclose uncertainty and avoid an
overconfident connection. Keep an internal locator for each added relationship so
[quality-checklist.md](quality-checklist.md) can review it. External enrichment
cannot substitute for invented evidence about what a prior lecture contained.
