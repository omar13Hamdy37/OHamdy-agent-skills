# Cheatsheets

**Status:** Phase 1 reference scaffold; operational instructions come in Phase 2.

## Purpose and scope

Own explicit and automatic cheatsheet decisions from requirement R. A cheatsheet
is a revision aid, not a replacement for the learning explanations.

## Key requirements

- Include one when requested, or when substantial syntax, formulas, rules,
  transformations, mappings, APIs/functions, comparisons, or patterns make it useful.
- Do not impose one on every lecture; respect explicit user preferences.
- Preserve necessary conditions, notation, and distinctions when compressing
  reference material. Make it accurate and quick to use during revision.
