# Teaching style

**Status:** Phase 1 reference scaffold; operational instructions come in Phase 2.

## Purpose and scope

Own explanation techniques and learner activities from requirements E–M. Apply
the priorities in [learning-philosophy.md](learning-philosophy.md); do not prescribe
one fixed chapter template for all subjects.

## Key requirements

- Explain unfamiliar domain terms immediately; avoid overdefining ordinary words.
- Use progressive tiny, realistic, and tricky examples when helpful, with correct
  code/output, assumptions, units, and calculations.
- Explain internal mechanisms when they resolve a learning gap; avoid unnecessary
  implementation detail.
- Add appropriate worked examples, prediction/debugging tasks, calculations,
  exercises, thought experiments, derivations, and “try it yourself” activities.
- Resolve relevant misconceptions with Common Confusion callouts; use concise
  comparisons when related concepts are easy to confuse.
- Reconstruct missing conceptual bridges and add compact understanding checkpoints
  after coherent groups of concepts.
- Adapt pedagogy to the discipline while using the same semantic visual system.
