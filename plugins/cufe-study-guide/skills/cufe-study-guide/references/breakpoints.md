# Conceptual breakpoints

Use for guides with multiple substantial learning units. Aim at approximately
30 minutes of focused studying, including reasoning and activities. Learner pace
varies; never assert exact timing or insert markers based only on page count.

## Plan units before estimating time

Use the concept map to mark indivisible sequences: proofs, derivations, worked
examples, algorithm walkthroughs, active dependency chains, and explanations that
need the immediately following section for closure. Finish these sequences before
considering a stop.

A later unit may reuse a completed concept. That settled prerequisite does not
forbid a break; an unfinished explanation does. For example, tokenization can be
complete before BPE begins, but BPE merge selection and applying the demonstrated
merge cannot be split while one worked example is still in progress.

## Judge workload qualitatively

| Signal | Effect on likely study effort |
| --- | --- |
| Several unfamiliar concepts or deep prerequisite chain | More integration and slower progress. |
| Derivation, dense notation, or non-obvious code | Time to trace steps and inspect assumptions. |
| Worked example followed by independent practice | Count solving/thinking effort, not only reading the explanation. |
| Familiar recap, simple lookup, or repeated pattern | Less effort; several short units may share a session. |
| Difficult comparison or misconception | Allow time to test the distinction on a new case. |

Choose light/moderate/heavy estimates rather than precise arithmetic. Group light
units until they form a useful session; give a demanding coherent unit room of its
own. Use the approximate 30-minute aim to reconsider candidate boundaries, not to
force a cut. Page length and word count can inform workload but cannot decide it.

## Select a boundary in this priority order

1. **Conceptual completion:** the learner can state/apply the unit's model.
2. **No unfinished dependency:** resumption does not require holding an unresolved
   step, intermediate calculation, or open example in mind.
3. **Natural transition:** the next section begins a distinct conceptual unit.
4. **Reasonable session size:** the accumulated effort is roughly useful for a
   focused session, permitting a somewhat shorter or longer chunk.

Reject any candidate that splits an indivisible sequence. If a demanding unit runs
long, prefer the next safe boundary; tighten redundancy or move optional detours
instead of breaking its reasoning. Do not omit required steps to meet the timing
aim. If the lecture is very short, use no breakpoint. Do not print a timing marker
at every checkpoint or at the end where no continuation remains.

## Write and review the note

Use a short **Good stopping point** note that identifies completion and the next
unit when that helps. For example:

> Good stopping point — you have completed the core idea of tokenization. BPE
> builds on that settled concept and begins a new study unit.

A compact “the next section begins a new conceptual unit” is sufficient when the
boundary is obvious. Avoid motivational fluff and false claims of independence.
After drafting, recheck the actual text and activities: planned boundaries may
become unsafe as explanations expand. Pair a useful checkpoint with a break when
both fit, but keep their purposes distinct. Final review belongs to
[quality-checklist.md](quality-checklist.md).
