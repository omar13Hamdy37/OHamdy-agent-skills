# Learning philosophy

**Status:** Phase 1 reference scaffold; operational instructions come in Phase 2.

## Purpose and scope

Own learning priorities, intuition-first organization, and the standalone-guide
standard. Govern explanatory tradeoffs across disciplines, not export mechanics.
The repository v1 specification is the development authority, especially A, B,
and M; it is not an installed runtime dependency.

## Key requirements

- Prioritize correctness, important-material completeness, understanding, practical
  learning, clarity, revision usefulness, appropriate conciseness, then presentation.
- Treat lectures as the syllabus while rewriting their order and wording when
  doing so improves learning.
- Prefer motivation and intuition before mechanisms, terminology, and examples;
  retain necessary rigor and formal language.
- Build a guide that normally stands alone. Adapt teaching sequence to programming,
  ML, signals/electronics, or theory while keeping consistent document semantics.
