# Independent pedagogical grading

Read the actual source and guide, including important diagrams. Do not judge by
word count, source slide length, heading presence, or a desired score. Expanded
explanation is expected; distinguish it from unsupported course claims. Record
guide section/block evidence, not long source quotations. The run's report is
private; only safe summarized scores/dispositions belong in public validation.

Use the same scale for every applicable dimension: **1** unusable/seriously wrong;
**2** substantial defects; **3** usable with meaningful weaknesses; **4** strong,
minor improvements possible; **5** excellent with no material gap found. Null
requires a genuine N/A rationale, never uncertainty disguised as inapplicability.

| ID | Assess |
| --- | --- |
| completeness | Essential concepts, methods, formulas and diagram relationships actually taught. |
| clarity | Learner can explain meaning and reason about new cases. |
| motivation | Useful purpose/why before detail; avoid forced stories. |
| terminology | First unfamiliar use explained accurately, without jargon recursion. |
| bridges | Dependencies and transitions reconstructed where needed. |
| mental_models | Mechanisms improve transferable understanding without trivia. |
| examples | Correct, relevant, appropriately progressive examples. |
| practice | Useful exercises and understanding checkpoints. |
| filtering | Admin/repetition removed; instructional foundations preserved. |
| confusions | Relevant plausible mistakes explained and corrected. |
| quiz | Compact coverage of understanding/application, not trivial vocabulary alone. |
| answers | Correct answers with reasoning; separate key; no mandatory optional-enrichment test. |
| standalone | Student can learn scoped material without continually reopening slides. |
| concision | Complete explanation without textbook detours/repeated callouts. |
| fidelity | No invented source/prior claims, fake links, or unlabeled beyond-course requirements. |

Coverage: each profile item gets covered/merged/condensed/intentionally omitted/
missing, a guide location and treatment/evidence. Names alone do not count as
coverage. Condensing a required procedure still preserves its useful steps.

Separately judge **filtering, no_prior_fabrication, breakpoints, cheatsheet, proofs,
quiz_correctness, source_fidelity**. Absence of a breakpoint, cheatsheet, or proof
can be correct. A source error should be explained accurately, not propagated.
If a score fails, inspect the actual evidence before recommending a repair.
